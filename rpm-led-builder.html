Showing example data (McLaren 720S GT3 EVO, Assetto Corsa Competizione) so you can see the tool working. Drag the preview slider past 7200 rpm to see the redline blink. Edit any field, or click Start blank to begin a new car from scratch, or Import JSON to edit an existing file.

Car identity

Suggested path: data/…/….json file name = Car ID, cleaned up the same way the repo does it
LMU files are generated. In Lovely Car Data, data/lmu/*.json is built from the templates in src_data/lmu/*.jsonc by scripts/build_profiles.py, and every build overwrites those files. Use this tool to work out the values, then put them in the matching template instead of submitting this file.

LED colors RL = redline flash · 1…N = strip, low→high RPM
