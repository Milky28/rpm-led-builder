LMU files are generated. In Lovely Car Data, data/lmu/*.json is built from the templates in src_data/lmu/*.jsonc by scripts/build_profiles.py, and every build overwrites those files. Use this tool to work out the values, then put them in the matching template instead of submitting this file.

Follows how ATSR lights these files: an LED lights once RPM is above its value (a value of 0 is always lit), and black or transparent LEDs are gaps that never light. Above the redline (RL) every LED shows the RL color and blinks at the blink interval, going dark in between; with a transparent RL color the LEDs keep their own colors. The swatch before the redline line shows the RL color.

    Try it on your wheel first (ATSR): download the file and put it in <SimHub folder>\_ATSR_DevelopmentData\rpm_data\ (no game subfolder), keeping the downloaded name. Turn on Developer Mode in ATSR's RPM settings, or switch it off and on to reload; restart SimHub if the lights don't change. Delete the file when you're done, or ATSR keeps using it.
